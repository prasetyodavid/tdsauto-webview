How it works

Each line: minutes per unit × volume in the period = workload for that task (minutes).

FTE = total workload minutes ÷ available minutes per person per period. Clear that field if you only want hours, not headcount.

Utilization on Home compares total workload to one person’s available minutes (same as FTE × 100% when availability is set).

Backup & restore
